# PyMOL Plugins

A collection of plugins for [PyMOL](https://pymol.org), aimed at structural /
computational chemistry workflows (docking poses and MD trajectories).

## Plugins

| Plugin | Description |
|--------|-------------|
| [noncovalent-interactions](noncovalent-interactions/) | Detects and draws non-covalent intermolecular interactions (H-bonds, salt bridges, π-π, π-cation, halogen, metal, water bridges, and more) as individual colour-coded dashed-line objects, with MD occupancy analysis, CSV export and publication presets. |

See each plugin's own `README.md` for installation and usage.
